# BLUEWAY Auto — frontend

Самостоятельный React/Vite-интерфейс каталога китайских автомобилей. В каталоге есть фильтры BEV/PHEV/EREV/ICE, комплектации, видеообзоры, статусы наличия и калькулятор доставки до Казахстана, России и Беларуси.

## Быстрый запуск

```bash
npm install
npm run dev
```

Production-сборка создаётся в `dist/`:

```bash
npm run build
npm run preview
```

Проект готов к импорту в Vercel как Vite-приложение. Настройки сборки и SPA-маршрутизации находятся в `vercel.json`.

## Важно

Формула калькулятора и данные каталога демонстрационные. При подключении backend их можно заменить API-вызовами без изменения компонентов карточек и фильтров.
